# The Add a piece menu, by topic: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the street page's Add a piece menu as eight topics (a topic column, a search box) where nothing vanishes: an item that cannot go on the street is greyed with its reason.

**Architecture:** The model says why stops, calming and green cannot be added (`View.unavailable`, `Said`). A new view-model module `street/vm/add_menu.rs` owns the topics, their items, the opening topic and the search, and `StreetVm::add_item` does the adding (or announces the reason). A pure key machine in `street/vm/keys.rs` moves the focus. `page::AddMenu` only binds these.

**Tech Stack:** Rust 2024, Leptos 0.8 (CSR, wasm32), Fluent `.ftl` (en, fr-CA), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-17-add-menu-design.md`

All paths below are under `crates/cityloom_editor/` unless they start with `web/`, `e2e/` or `docs/`.

## Global Constraints

- Test first; commit each task once `just test` passes; `just format` before each commit; CI uses `RUSTFLAGS=-D warnings`.
- Every new string in both `src/street/i18n/en.ftl` and `fr.ftl`, same id and variables; whole sentences; plurals by selector; fr-CA after the OQLF (no-break space before `:` and inside `« »`), terms from `docs/glossary-fr-ca.md` (« élément » is a piece of the street, never a tree or a bed).
- The view decides nothing: which items, in which topic, greyed with what reason, what matches, where the focus goes: all from `street/vm/`, tested natively.
- WCAG 2.2 AA: targets ≥ 24 px (44 px on a coarse pointer); a new colour pair goes in `shared/contrast.rs`.
- The Transform menu behaves exactly as before (its tests unchanged and passing).
- What each item adds, and where, is unchanged.
- Version: minor bump of `version` in `crates/cityloom_editor/Cargo.toml` (0.92.0 → 0.93.0, or the next minor if main has moved), then `cargo update -p cityloom_editor`.

## Review Focus

1. Typing a French name with or without accents, apostrophes or no-break spaces (« arret », « cafe », "Café terrace") finds the item; a test in Task 1 and Task 3 pins each.
2. A language switch while the menu is open re-words topics, items, reasons and search matches (Task 5 component test in fr; Task 6 `language.spec.ts`).
3. The street changes under an open menu (undo removes the only bus lane): the stops turn greyed with their reason, the open topic stays (Task 3 test `entries_follow_the_view`).
4. A greyed item chosen by keyboard (Enter) adds nothing, keeps the menu open and announces the reason (Task 3 VM test, Task 6 e2e).
5. A search with no match, then cleared, returns to the topic that was showing (Task 5 component test, Task 6 e2e).

impl Topic {

}

/// Where an item goes, which also groups a topic's items into runs.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Run { Pieces, Green, Stops, Calming }
impl Run {
    pub fn id(self) -> &'static str;           // "pieces", "green", "stops", "calming"
    pub fn hint_key(self) -> &'static str;     // "add-hint", "add-hint-green", "add-hint-stretch", "add-hint-stretch"
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Item { Piece(usize), Green(GreenKind), Stop(StopKind), Calming(CalmingKind) }
impl Item {
    pub fn run(self) -> Run;
    pub fn name_key(self) -> String;           // kind_key(KINDS[k].id), or the kind's name_key()
    pub fn size_mm(self) -> Option<i32>;       // piece: KINDS[k].default_mm; stop: stop_min_mm(); calming: default_mm(); green: None
}

pub fn topic_items(topic: Topic) -> Vec<Item>;     // the spec's table, in its order
pub fn topic_of(item: Item) -> Topic;
pub fn opening_topic(level: Level, v: &View) -> Topic;
pub fn insert_index(v: &View) -> usize;            // moved unchanged from page.rs

/// One item as the menu shows it.
#[derive(Clone, Debug, PartialEq)]
pub struct Entry { pub item: Item, pub topic: Topic, pub unavailable: Option<Said> }

pub fn entries(v: &View, topic: Topic) -> Vec<Entry>;
/// Every item whose name in `i18n`'s language holds `query` (both folded), in topic order; empty for a blank query.
pub fn search(v: &View, i18n: &I18n, query: &str) -> Vec<Entry>;
