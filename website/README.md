# CityLoom documentation site

The documentation of CityLoom, built with [Docusaurus](https://docusaurus.io/) in English and Canadian French.
The pages are in `docs/` (English) and `i18n/fr-CA/docusaurus-plugin-content-docs/current/` (French). From the
repository root, `just docs` serves the site and `just docs-build` builds both languages.
