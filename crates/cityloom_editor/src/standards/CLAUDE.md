# Standards slice (`src/standards/`; #79)

Loaded when working in this folder; the root `CLAUDE.md` has the project-wide rules.

Project-specific design standards: a profile of local thresholds the street page's checks read in place of the built-in ones. v1 scope is the street page only; junction, restriction, area-rule and map network checks (#126) stay on the built-in constants.

- `model.rs`: `Standards` (its `Default` is today's built-in set: `ACCESS_LANE_MM`, `CROSSING_CLEARANCE_MM`, `DOOR_BUFFER_MM`, `PATIO_WALK_MM`, `MIN_STOP_MM`, `SPEED_CHOICES`, which now live here and are re-exported by `street::model`; plus `kind_widths` by kind id, `target_kmh` by class id), `validate()` -> `Refusal` (data; `said()` is the reason, a `Said` with the range or limit), `warnings()` (allowed but looser than built-in: shown, never blocks), `Field`, `WidthRange`. The model holds no wording.
- **Active profile:** a thread-local (`set_active`, `Active { name, standards }`); the wasm module is single-threaded and every test thread has its own. Accessors `access_lane_mm()`, `crossing_clearance_mm()`, `door_buffer_mm()`, `patio_walk_mm()`, `stop_min_mm()`, `speed_choices()`, `kind_bounds(kind)`, `target_kmh(class)` fall back to the built-in figure when none is active, so a street with no profile is checked exactly as before. A test that activates one holds `activate_for_test(..)`'s guard (it puts the built-in figures back on drop).
- **Notes:** `note(Field)`, `note_width(kind)`, `note_target(class)`, `note_speeds()` give the `Said` "Standard X: 3.5 m (built-in 3.0 m)" (args `name`, `value`, `builtin`; none with no profile). `street::model::Check.standard` carries it (set in `Editor::street_checks` by `profile.rs`); the Checks tab, and the width range in the inspector, print it.
- **Only the street page activates a profile:** `street::open_street_in` calls `store::activate` before the street is read. The map and junction pages never do, so they stay on the built-in figures: the map's "flagged only for checks a change makes worse than first laid out" baseline is therefore the built-in standard, and `map::network` still words `ACCESS_LANE_MM`.
- `store.rs`: `StandardsStore` over the browser-wide `cityloom-standards` (`{version, active, next_id, profiles:[{id, name, standards}]}`; not one of `scoped::SCOPED_KEYS`, so every project reads the same; never marked for the sync, no `Kind`, no server change). Future version left alone (`Refusal::Newer`); damaged copied to `cityloom-standards-damaged`; each write re-reads and re-activates. Create (built-in figures), rename, update, select (one active), remove, `export` (standalone `{schema: "cityloom-standards", schema_version: 1, name, standards}`) and `import` (same `validate`, a name taken is refused, never chosen by importing). Names unique ignoring case, at most 60 characters; at most 20 profiles.
- `vm.rs`, `view.rs`, `text.rs`, `i18n/`: the Profiles section (`#standards-slot` on the street page's Street tab). `StandardsVm::new(ports, i18n, units, on_change)` takes the page's units and a change callback as closures, since this slice may not use the street's view-model; `lib.rs::mount_standards(sheet)` (the composition root) wires them and `web/app.js` calls it. Typed lengths go through `parse_length_mm` in the page's units, speeds are a comma list (sorted, deduplicated), a blank target is none; nothing is kept unless all of it validates.
- Checks that read a profile: `access`, `curb-crossing`, `curb-bike`, `curb-sidewalk`, `stop-length`, plus `speed-target` (exists only when the profile sets a target for the street's class; highest zone speed over it fails). Widths: `Segment::bounds`, the add and import clamps and the measures read `kind_bounds`; the range must contain the kind's default width, so `clamp` can never panic.
- May use `shared`; `street` uses only `standards::model` and `standards::store`. Never another slice's `vm`, views or text.
- Known limits: junction/restriction/area checks and the map's network checks ignore profiles; a profile changed in another tab shows on this page after a reload; the export is shown to copy or download (a `data:` link), import is pasted text (no file picker); the curb uses' own minimum lengths and the calming figures are not profile-settable.
