# Share slice (`src/share/`)

Loaded when working in this folder; the root `CLAUDE.md` has the project-wide rules.

Sharing a design by a link (#221; decisions in the issue's comments): a snapshot of a whole project (streets, junctions, area rules) kept on the server for 90 days behind an unguessable link, opened read-only (`view=1`, #222) by anyone with the link, no account needed. Server side: `cityloom_server`'s `share.rs` and `/api/share` (see its `CLAUDE.md`). Privacy and retention for people: `website/docs/sharing.md` (and fr-CA).

- `model.rs` (no wording, no I/O of its own): the format, ONE JSON document `{kind: "cityloom-share", format_version: 1, app_version, created_at, project: {name, area}, edits?, restrictions?}`; `edits` and `restrictions` are the project's raw `cityloom-edits` and `cityloom-restrictions` documents (unknown records and fields pass through); no milestones, nothing of the account, the sync or settings. Integer version, higher refused (`Newer`), unknown fields ignored (the archive's rules). `compose(project storage, name, area, app_version, created_at)` refuses `Unusable` (a document this build cannot read back) and `TooLarge` (over `MAX_BYTES`, 1 MiB, the server's limit; never cut). `parse_and_validate` checks everything before anything is kept: header, name (`project::model::clean_name`), area (`Area::from_query`), and the two documents through `archive::model::{read_edits, read_rules}`. `ShareError` (data; `said()` keys `share-error-*`, each opening failure ending "Nothing was kept on this device."), `From<ShareFailure>`. `valid_token` (43 base64url characters), `link(origin, token)` = `<origin>/share.html#<token>`: the token rides in the fragment, never sent to a server or in a `Referer`.
- `store.rs`: `ShareStore` over `cityloom-shares` (a `SCOPED_KEYS` key, so per project and blanked with it): the links made on this device (`{token, created_at, expires_at}`), so their maker can copy and delete them. Never synced: the server keeps no token, so a link is listed only on the device that made it.
- `vm.rs`: `ShareVm::new(project ports, i18n, Context { project_name, project_area, app_version })` (`share.html?project=<id>`): `load_account` (`/api/me`: signed in or out), `blocked()` (signed out, or the storage is read-only), `create` (compose, `ShareApi::create`, keep, announce `share-created` with the expiry day, focus the link field), `copy` (`Page::copy_text`), `delete` (forgotten also on not-found/expired/deleted; kept on not-yours or a network failure), `links()` newest first with `share-until`/`share-expired-on`. `OpenVm::new(root ports, i18n)` (`share.html#<token>`): `start` asks `ShareApi::open` only for a whole token (else `BadLink`, no request), validates, keeps a copy with `project::copies::keep` (never marked, never synced, not one of the person's projects; the same link replaces its copy) and `Navigator::replace`s to `map.html?project=<copy>&view=1`; any failure is `Opening::Failed` and writes nothing.
- `text.rs`: the expiry day (`share-date`, UTC). `view.rs`: `ShareView` (intro, retention, create button disabled while signed out/unknown/busy with the reason shown, outcome, the links: a labelled read-only field, copy, delete), `OpenView` (one `role="status"` while working, one `role="alert"` for the failure, link to `index.html`).
- Page: `web/share.html`, `web/share.js`, `web/share.css`; `lib.rs::mount_share` is the composition root: `model::opens_a_link(hash, search)` (a whole token, or a fragment that is not the account's where no `project=` is named) opens the link (root ports, after `move_legacy_work`), else `project::context::open_page` and the project's record. The home page's project row links to it (`project-share`); `share.html` is one of `PROJECT_PAGES`.
- May use `shared`, `archive::model` (the validators), `project::model`, `project::store::find`, `project::copies`, `place::area`, `city::edits`, `restriction::store`, `sync::model::stamp`; never another slice's `vm`, views or text.
- Known limits: a link is listed (and deletable from the page) only on the device that made it; deleting the account removes every share. A copy shows the design as shared; the place's roads come from OpenStreetMap on the opener's device.
