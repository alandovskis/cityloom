# Place slice (`src/place/`)

Loaded when working in this folder; the root `CLAUDE.md` has the project-wide rules.

- `area.rs` (`Area`, kept under its position; the catalogue of metropolitan areas: `Metro { id, name (a `Said`, `place-metro-<id>` in `place/i18n`), the box it covers, start }`, `metros()` (default first), `default_metro()`, `metro(id)`, `metro_of(area)` (the one holding the area's centre), `Metro::start()` (the place a new project's map opens on: the editor opens one place about 800 m across, `HALF_M`, never a whole region); Montréal (`MONTREAL`, `"montreal"`) is the only entry, starting on the Plateau; `default_area()` = the default metro's start; `is_montreal` = held by Montréal's box. A second metropolitan area is an entry, its name in both `.ftl` files, and its tiles in the tile index (whose grid is Montréal's: tile names are non-negative `x_y` from `lon0`/`lat0`, and the builder's `tiles` makes Montréal's grid only)), `tiles.rs` (the metro tile index and the tiles that hold a place), `loader.rs` (`Loader`: fetch, merge, cut, keep roads, via ports), `prepare_city` export (the page's project's area, else the default).
- No place search: a project's metropolitan area is chosen in the create form (`project::vm`, from `metros()`) and fixed then; nothing chooses a place (`CityStore::choose` has no UI caller). The pages open the area of their project: `CityStore::current_area` reads the area the project's record names (`project::context::area_of`); only where there is no such record (root storage, a project not listed, a placeholder, an area that does not parse) the project's `cityloom-area@<id>`, else the default area.
- `Loader::load` reads roads from the metro network tiles only: it fetches `data/metro/index.json`, then the tile whose core holds the place's centre and any other listed tile the place's box reaches, merges them by id (`Network::absorb`), cuts the place out (`Network::clip_to` into `area.bounds().frame()`) and keeps it with the tile's checksum plus `cityloom_model::IMPORTER_VERSION`. There is no Overpass and no importer in the browser: a place no tile holds is not covered (`place-not-covered`, nothing kept); roads already kept stand when the index or a tile cannot be had.
